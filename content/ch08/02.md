# 8.2 I/O 指令

80386 的 I/O 指令提供对处理器 I/O 端口的访问，用于与外围设备之间传送数据。这些指令把一个操作数作为 I/O 地址空间中的端口地址。I/O 指令有两类：

1. 传送位于寄存器中的单个项（字节、字或双字）；
2. 传送位于内存中的项串（字节串、字串或双字串），称为“串 I/O 指令”或“块 I/O 指令”。

## 8.2.1 寄存器 I/O 指令

`IN` 和 `OUT` 指令用于在 I/O 端口与 EAX（32 位 I/O）、AX（16 位 I/O）或 AL（8 位 I/O）通用寄存器之间传送数据。`IN` 和 `OUT` 既可以直接寻址 I/O 端口——指令中编码最多 256 个端口地址之一，也可以通过 DX 寄存器间接寻址最多 64K 个端口地址之一。

`IN`（从端口输入）把字节、字或双字从输入端口传送到 AL、AX 或 EAX。若程序在 `IN` 指令中指定 AL，处理器从所选端口传送 8 位到 AL；指定 AX 则传送 16 位到 AX；指定 EAX 则传送 32 位到 EAX。

`OUT`（输出到端口）把字节、字或双字从 AL、AX 或 EAX 传送到输出端口。程序可以用与 `IN` 相同的方法指定端口号。

## 8.2.2 块 I/O 指令

块（串）I/O 指令 `INS` 和 `OUTS` 在 I/O 端口与内存空间之间传送数据块。块 I/O 指令用 DX 寄存器指定 I/O 地址空间中的端口地址。`INS` 和 `OUTS` 用 DX 指定：

- 编号 0–65535 的 8 位端口；
- 编号 0、2、4、…、65532、65534 的 16 位端口；
- 编号 0、4、8、…、65528、65532 的 32 位端口。

块 I/O 指令用 SI 或 DI 指定源或目的内存地址。每次传送后，SI 或 DI 按标志寄存器中方向位的指示自动递增或递减。

`INS` 和 `OUTS` 与重复前缀配合使用时，执行块输入或输出操作。重复前缀 `REP` 修饰 `INS` 和 `OUTS`，提供在 I/O 端口与内存之间传送数据块的手段。这些块 I/O 指令是串原语（串原语的更多内容见第 3 章）。它们省去了单独的 `LOOP` 指令或保存数据的中间寄存器，从而简化编程并提高传送速度。

串 I/O 原语可以操作字节串、字串或双字串。每次传送后，ESI 或 EDI 中的内存地址按操作数大小更新：字节操作数加 1，字操作数加 2，双字操作数加 4。方向标志 DF 的值决定处理器自动递增 ESI/EDI（DF=0）还是自动递减（DF=1）。

`INS`（从端口输入串）把字节或字串元素从输入端口传送到内存。助记符 `INSB`、`INSW`、`INSD` 是显式指定操作数大小的变体。若程序指定 `INSB`，处理器从所选端口传送 8 位到 ES:EDI 指示的内存位置；`INSW` 传送 16 位；`INSD` 传送 32 位。`INS` 指令的目的段寄存器（ES）不能改变。与 `REP` 前缀配合时，`INS` 把一块信息从输入端口传送到一系列连续的内存位置。

`OUTS`（向端口输出串）把字节、字或双字串元素从内存传送到输出端口。助记符 `OUTSB`、`OUTSW`、`OUTSD` 是显式指定操作数大小的变体。若程序指定 `OUTSB`，处理器从 ES:EDI 指示的内存位置传送 8 位到所选端口；`OUTSW` 传送 16 位；`OUTSD` 传送 32 位。与 `REP` 前缀配合时，`OUTS` 把一块信息从 DS:ESI 指示的一系列连续内存位置传送到输出端口。
