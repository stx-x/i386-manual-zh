# 3.6 串与字符转换指令

这一类指令作用于串，而不是逻辑值或数值。串 I/O 指令（也称块 I/O）另见输入/输出一节。

80386 串操作的威力来自体系结构的以下特性：

- **一组基本串操作**：`MOVS`（传送串）、`CMPS`（比较串）、`SCAS`（扫描串）、`LODS`（装入串）、`STOS`（存储串）。
- **间接索引寻址**，索引自动递增或递减。索引寄存器为 ESI（源索引）和 EDI（目的索引）；控制标志为 DF（方向标志），由 `CLD`（清方向标志）和 `STD`（置方向标志）控制。
- **重复前缀**：`REP`（ECX 非零时重复）、`REPE`/`REPZ`（相等或为零时重复）、`REPNE`/`REPNZ`（不相等或不为零时重复）。

基本串操作每次处理串中的一个元素。串元素可以是字节、字或双字。串元素由 ESI 和 EDI 寄存器寻址。每次基本操作之后，ESI 和/或 EDI 自动更新，指向串的下一个元素。若方向标志为 0，索引寄存器递增；为 1 则递减。递增或递减的量为 1、2 或 4，取决于串元素的大小。

## 3.6.1 重复前缀

重复前缀 `REP`（ECX 非零时重复）、`REPE`/`REPZ`（相等/为零时重复）和 `REPNE`/`REPNZ`（不相等/不为零时重复）规定重复执行某个串原语。这种迭代方式使 CPU 处理串的速度远快于普通的软件循环。

当串原语带有重复前缀时，操作反复执行，每次使用串的不同元素。当满足前缀规定的某个条件时，重复终止。

每次重复执行原语指令时，串操作可能暂时挂起，以处理异常或外部中断；中断之后，串操作可以从断点处重新开始。这种处理方式允许对任意长度的串进行操作，而不影响中断响应。

三种前缀都会让硬件自动重复相关串原语，直到 ECX=0。它们的区别在于第二个终止条件。`REPE`/`REPZ` 和 `REPNE`/`REPNZ` 只与 `SCAS`（扫描串）和 `CMPS`（比较串）原语配合使用。使用这些前缀时，下一条指令是否重复取决于零标志 ZF 以及 ECX 寄存器。重复串指令执行前无需初始化 ZF，因为 `SCAS` 和 `CMPS` 会根据比较结果设置 ZF。区别汇总于下表。

| 前缀 | 终止条件 1 | 终止条件 2 |
|---|---|---|
| `REP` | ECX = 0 | （无） |
| `REPE` / `REPZ` | ECX = 0 | ZF = 0 |
| `REPNE` / `REPNZ` | ECX = 0 | ZF = 1 |

## 3.6.2 索引与方向标志控制

串原语操作数的地址由 ESI 和 EDI 寄存器确定。ESI 指向源操作数，默认位于 DS 段寄存器指示的段中；不过可以用段超越前缀让 ESI 指向 CS、SS、ES、FS 或 GS。EDI 指向 ES 段中的目的操作数，不能使用段超越。一条指令中使用两个不同的段寄存器，使串能够在不同段之间搬移。

ESI 和 EDI 的这种用途，使它们分别获得了“源索引”和“目的索引”的名称。但在串指令以外的所有场合，ESI 和 EDI 都可以作为通用寄存器使用。

在串原语中使用 ESI 和 EDI 时，操作之后它们会自动递增或递减，由方向标志决定方向。`CLD` 指令把 0 放入 DF，使索引寄存器递增；`STD` 把 1 放入 DF，使索引寄存器递减。程序员在过程中使用串指令之前，应始终给 DF 赋予已知值。

## 3.6.3 串指令

`MOVS`（传送串）把 ESI 指向的串元素传送到 EDI 指向的位置。`MOVSB` 处理字节元素，`MOVSW` 处理字元素，`MOVSD` 处理双字。目的段寄存器不能被段超越前缀覆盖，但源段寄存器可以覆盖。

`MOVS` 与 `REP` 前缀配合时，相当于内存到内存的块传送。为此，程序必须初始化 ECX 以及 ESI、EDI 寄存器对。ECX 指定块中的字节、字或双字数量。

若 DF=0，程序必须让 ESI 指向源串的第一个元素，让 EDI 指向第一个元素的目的地址；若 DF=1，则分别指向源串的最后一个元素和最后一个元素的目的地址。

`CMPS`（比较串）用源串元素（ESI 处）减去目的串元素（ES:EDI 处），并更新 AF、SF、PF、CF 和 OF。若两个串元素相等，ZF=1；否则 ZF=0。若 DF=0，处理器递增两个串的内存指针（ESI 和 EDI）。`CMPSB` 比较字节，`CMPSW` 比较字，`CMPSD` 比较双字。源地址所用的段寄存器可以用段超越前缀改变，目的段寄存器不能覆盖。

`SCAS`（扫描串）用 EAX、AX 或 AL 减去 ES:EDI 处的目的串元素，并更新 AF、SF、ZF、PF、CF 和 OF。若值相等，ZF=1；否则 ZF=0。若 DF=0，处理器递增串的内存指针（EDI）。`SCASB` 扫描字节，`SCASW` 扫描字，`SCASD` 扫描双字。目的段寄存器（ES）不能被覆盖。

当 `REPE` 或 `REPNE` 前缀修饰 `SCAS` 或 `CMPS` 原语时，处理器把当前串元素与 EAX（双字元素）、AX（字元素）或 AL（字节元素）中的值比较。重复操作是否终止，取决于 ZF 的结果状态以及 ECX 的值。

`LODS`（装入串）把 ESI 处的源串元素放入 EAX（双字串）、AX（字串）或 AL（字节串）。`LODS` 根据 DF 递增或递减 ESI。

`STOS`（存储串）把 EAX、AX 或 AL 中的源串元素放入 ES:EDI 处的串。`STOS` 根据 DF 递增或递减 EDI。
