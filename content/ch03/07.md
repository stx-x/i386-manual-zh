# 3.7 面向块结构语言的指令

本节指令为高级语言中常见的功能提供机器语言支持，包括简化过程编程的 `ENTER` 和 `LEAVE`。

`ENTER`（进入过程）建立一个栈帧，可用于实现块结构高级语言的作用域规则。过程末尾的 `LEAVE` 与过程开头的 `ENTER` 配对，简化栈管理，并控制嵌套过程对变量的访问。

`ENTER` 有两个参数。第一个参数指定为被进入的例程在栈上分配的动态存储字节数；第二个参数对应该例程的词法嵌套层级（0–31）。（注意，词法层级与保护特权级、I/O 特权级都没有关系。）

指定的词法层级决定 CPU 从前一个栈帧复制多少组栈帧指针到新栈帧中。这个栈帧指针列表有时称为 **display**。display 的第一个字是指向最后一个栈帧的指针，`LEAVE` 指令借助它撤销前一条 `ENTER` 的动作，实际上就是丢弃最后一个栈帧。例如：

```
ENTER 2048,3
```

在栈上分配 2048 字节动态存储，并在 `ENTER` 为此过程创建的栈帧中建立指向两个先前栈帧的指针。`ENTER` 为过程建立新的 display 之后，把 ESP 减去第一个参数指定的字节数，从而为该过程分配动态存储空间。ESP 的新值成为该过程内所有 `PUSH`、`POP` 操作的起点。

为了让过程能够访问自己的 display，`ENTER` 让 EBP 指向新栈帧的起点。以 EBP 为基址寄存器的数据操作指令，会隐含访问栈段而不是数据段中的位置。

`ENTER` 有两种用法：嵌套和非嵌套。若词法层级为 0，则使用非嵌套形式：第二个操作数为 0，`ENTER` 压入 EBP，把 ESP 复制到 EBP，然后从 ESP 中减去第一个操作数。当第二个参数（词法层级）不为 0 时，使用嵌套形式。

主过程（其中嵌套其他过程）运行在最高词法层级，即第 1 层。它调用的第一个过程运行在下一个更深的词法层级，即第 2 层。第 2 层过程可以访问主程序的变量，这些变量位于编译器指定的固定位置。对于第 1 层，`ENTER` 只在栈上分配请求的动态存储，因为没有先前的 display 可复制。

运行在较高词法层级的程序调用较低词法层级的程序时，要求被调用过程能够访问调用程序的变量。`ENTER` 通过 display 提供这种访问，display 给出了调用程序栈帧的地址。

一个过程调用同一词法层级的另一个过程，意味着它们是平行过程，被调用过程不应访问调用过程的变量。此时，`ENTER` 只复制调用过程 display 中与更高词法层级的先前嵌套过程有关的那一部分；新栈帧不包含用于寻址调用过程栈帧的指针。

`ENTER` 把可重入过程视为调用同一词法层级的另一个过程。此时，可重入过程每次迭代只能访问自己的变量以及更高词法层级调用过程的变量。可重入过程总能访问自己的变量，不需要指向前几次迭代栈帧的指针。

通过只复制更高词法层级过程的栈帧指针，`ENTER` 确保过程只访问更高词法层级的变量，而不访问平行词法层级的变量（见图 3-17）。图 3-18 至图 3-21 演示了图 3-17 中的模块按字母顺序相互调用时 `ENTER` 指令的动作。

块结构高级语言可以利用 `ENTER` 定义的词法层级，控制对先前嵌套过程变量的访问。以图 3-17 为例，若过程 A 调用过程 B，B 又调用过程 C，则过程 C 可以访问 MAIN 和过程 A 的变量，但不能访问过程 B 的变量，因为 B 与 C 处于同一词法层级。图 3-17 的变量访问规则完整如下：

1. 主程序（MAIN）的变量位于固定位置。
2. 过程 A 只能访问 MAIN 的固定变量。
3. 过程 B 只能访问过程 A 和 MAIN 的变量，不能访问过程 C 或 D 的变量。
4. 过程 C 只能访问过程 A 和 MAIN 的变量，不能访问过程 B 或 D 的变量。
5. 过程 D 可以访问过程 C、过程 A 和 MAIN 的变量，不能访问过程 B 的变量。

MAIN 开头的 `ENTER` 为 MAIN 创建动态存储空间，但不复制任何指针。display 中第一个也是唯一的一个字指向它自身，因为没有先前的值可供 `LEAVE` 恢复 EBP。见图 3-18。

MAIN 调用过程 A 之后，`ENTER` 为过程 A 建立新的 display：第一个字指向前一个 EBP 值（供 `LEAVE` 返回 MAIN 栈帧），第二个字指向当前 EBP 值。过程 A 可以访问 MAIN 的变量，因为 MAIN 位于第 1 层，所以 MAIN 动态存储的基址在 [EBP−2]；MAIN 的所有动态变量都相对于该值有固定偏移。见图 3-19。

过程 A 调用过程 B 之后，`ENTER` 为过程 B 建立新的 display：第一个字指向前一个 EBP 值，第二个字指向 MAIN 的 EBP 值，第三个字指向 A 的 EBP 值，最后一个字指向当前 EBP。B 可以从 display 中取得各动态存储区的基址，从而访问 A 和 MAIN 的变量。见图 3-20。

过程 B 调用过程 C 之后，`ENTER` 为过程 C 建立新的 display：第一个字指向前一个 EBP 值，第二个字指向 MAIN 的 EBP 值，第三个字指向 A 的 EBP 值，最后一个字指向当前 EBP。因为过程 B 与过程 C 处于同一词法层级，C 不允许访问 B 的变量，因此不会收到指向 B 栈帧起点的指针。见图 3-21。

`LEAVE`（离开过程）撤销前一条 `ENTER` 指令的动作。`LEAVE` 不带操作数：它把 EBP 复制到 ESP，释放最近一条 `ENTER` 分配给该过程的所有栈空间，然后从栈上弹出旧的 EBP 值。随后的 `RET` 指令即可清除调用程序为被调用过程压入栈的参数。
