# 3.9 协处理器接口指令

数值协处理器（如 80387 或 80287）为基础体系结构的指令集提供扩展，支持高精度整数和浮点运算。扩展指令集包括算术、比较、超越函数和数据传送指令。协处理器还含有一组有用的常数，用于提高数值计算速度。

程序中协处理器指令与 CPU 指令排在一起，系统按它们在指令流中出现的顺序执行。协处理器与 CPU 并发工作，为数值计算提供最大吞吐量。

80386 还具备在协处理器缺席时模拟数值协处理器的特性。协处理器的软件模拟对应用软件透明，但执行时间更长。协处理器模拟的更多信息见第 11 章。

`ESC`（转义）是一个 5 位序列，用于引出标识浮点数值指令的操作码。ESC 模式告诉 80386 把操作码和操作数地址发送给数值协处理器。数值协处理器用转义指令执行符合 IEEE 754 浮点标准的高性能、高精度浮点运算。

`WAIT`（等待）是一条 80386 指令，它挂起程序执行，直到 80386 CPU 检测到 BUSY 引脚无效。该状态表明协处理器已经完成处理任务，CPU 可以取得结果。
