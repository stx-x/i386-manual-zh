# 3.4 逻辑指令

逻辑指令组包括：

- 布尔运算指令
- 位测试与修改指令
- 位扫描指令
- 循环移位与移位指令
- 条件置字节指令

## 3.4.1 布尔运算指令

逻辑运算包括 AND、OR、XOR 和 NOT。

`NOT`（求反）把指定操作数的各位取反，形成该操作数的反码。`NOT` 是一元操作，只使用一个位于寄存器或内存中的操作数。`NOT` 不影响标志。

`AND`、`OR` 和 `XOR` 执行标准的逻辑“与”“（包含）或”和“异或”运算。这些指令可以使用以下操作数组合：

- 两个寄存器操作数；
- 一个通用寄存器操作数与一个内存操作数；
- 一个立即操作数与一个通用寄存器操作数或内存操作数。

`AND`、`OR` 和 `XOR` 清零 OF 和 CF，使 AF 未定义，并更新 SF、ZF 和 PF。

## 3.4.2 位测试与修改指令

这组指令作用于单个位，该位可以在内存或通用寄存器中。位的位置以相对于操作数低端的偏移指定。偏移值可以由指令中的立即字节给出，也可以存放在通用寄存器中。

这些指令先把所选位的值赋给进位标志 CF，然后按操作要求给该位赋新值。OF、SF、ZF、AF、PF 保持未定义。表 3-1 定义了这些指令。

| 指令 | 对 CF 的影响 | 对所选位的影响 |
|---|---|---|
| `BT`（位测试） | CF := BIT | （无） |
| `BTS`（位测试并置位） | CF := BIT | BIT := 1 |
| `BTR`（位测试并复位） | CF := BIT | BIT := 0 |
| `BTC`（位测试并求反） | CF := BIT | BIT := NOT(BIT) |

## 3.4.3 位扫描指令

这些指令扫描一个字或双字，寻找值为 1 的位，并把第一个置位位的索引存入寄存器。被扫描的位串可以在寄存器或内存中。若整个字为零（未找到置位位），则置位 ZF；若找到值为 1 的位，则清零 ZF。若未找到置位位，目的寄存器的值未定义。

`BSF`（向前位扫描）从低位向高位扫描（从位索引 0 开始）。

`BSR`（反向位扫描）从高位向低位扫描（从字的位索引 15 或双字的位索引 31 开始）。

## 3.4.4 移位与循环移位指令

移位和循环移位指令重新排列指定操作数中各位的位置。这些指令分为以下几类：

- 移位指令；
- 双精度移位指令；
- 循环移位指令。

### 3.4.4.1 移位指令

字节、字和双字中的位可以按算术或逻辑方式移位。根据指定的计数值，最多可以移位 31 位。

移位指令可以用三种方式指定计数：第一种形式隐含计数为 1；第二种形式把计数作为立即数；第三种形式把计数作为 CL 中的值。最后一种形式允许移位计数成为程序在执行期间提供的变量。只使用 CL 的低 5 位。

CF 总是含有最后一位移出目的操作数的值。在单比特移位中，若最高（符号）位的值因操作而改变，则置位 OF；否则清零 OF。但在多比特移位之后，OF 的内容总是未定义。

移位指令提供了按 2 的幂进行除法或乘法的便捷方法。但要注意，对有符号数右移并不等同于 `IDIV` 指令执行的除法。

`SAL`（算术左移）把目的字节、字或双字操作数左移 1 位，或左移计数操作数（立即数或 CL 中的值）指定的位数。当位从操作数左侧（高位）移出时，处理器从右侧（低位）移入 0。见图 3-6。

`SHL`（逻辑左移）是 `SAL` 的同义词（参见 `SAL`）。

`SHR`（逻辑右移）把目的字节、字或双字操作数右移 1 位，或右移计数操作数指定的位数。当位从右侧移出时，处理器从左侧移入 0。见图 3-7。

`SAR`（算术右移）把目的字节、字或双字操作数右移 1 位，或右移计数操作数指定的位数。处理器保持操作数的符号：若值为正，从左侧（高位）移入 0；若值为负，则移入 1。见图 3-8。

尽管这条指令可以用来把整数除以 2 的幂，但这种除法与 `IDIV` 指令产生的除法并不相同。`IDIV` 的商向零舍入，而 `SAR` 的“商”向负无穷舍入。这一差别只在负数时显现。例如，用 `IDIV` 把 −9 除以 4，结果是 −2，余数为 −1；若用 `SAR` 把 −9 右移两位，结果是 −3。这种除法的“余数”是 +3，但 `SAR` 只把余数的高位（存入 CF）。

图 3-9 中的代码序列对任意 M = 2^(N)（0 < N < 32）都能产生与 `IDIV` 相同的结果。该序列大约需要 12 到 18 个时钟，取决于是否发生跳转；若 ECX 中存放 M，对应的 `IDIV ECX` 指令约需 43 个时钟。

### 3.4.4.2 双精度移位指令

这些指令提供了处理长的非对齐位串所需的基本操作。双精度移位作用于字或双字操作数，方式如下：

1. 输入两个字操作数，产生一个字的结果；
2. 输入两个双字操作数，产生一个双字的结果。

两个输入操作数中，一个可以在通用寄存器或内存中，另一个只能在通用寄存器中。结果替换内存或寄存器操作数。移位的位数由 CL 寄存器或指令中的立即字节指定。

位从寄存器操作数移入内存或寄存器操作数。CF 置为最后一位移出目的操作数的值。SF、ZF、PF 根据结果设置，OF 和 AF 保持未定义。

`SHLD`（双精度左移）把 R/M 字段的位左移，同时把 Reg 字段的高位从右侧移入 R/M 字段（见图 3-10）。结果存回 R/M 操作数，Reg 字段不变。

`SHRD`（双精度右移）把 R/M 字段的位右移，同时把 Reg 字段的低位从左侧移入 R/M 字段（见图 3-11）。结果存回 R/M 操作数，Reg 字段不变。

### 3.4.4.3 循环移位指令

循环移位指令可以循环移动字节、字和双字中的位。移出操作数的位不会像移位那样丢失，而是“绕回”操作数的另一端。

循环移位只影响进位和溢出标志。在两条循环移位指令中，CF 可以作为操作数的扩展，从而隔离出一位，再用条件跳转指令（`JC` 或 `JNC`）测试。CF 总是含有最后移出的位的值，即使指令并未把该位用作循环操作数的扩展。

在单比特循环移位中，若操作改变了目的操作数的最高（符号）位，则置位 OF；若符号位保持原值，则清零 OF。多比特循环移位后，OF 的值总是未定义。

`ROL`（循环左移）把目的字节、字或双字操作数左移 1 位，或左移计数操作数指定的位数。每循环一次，从操作数左侧移出的最高位从右侧返回，成为新的最低位。见图 3-12。

`ROR`（循环右移）把目的字节、字或双字操作数右移 1 位，或右移计数操作数指定的位数。每循环一次，从操作数右侧移出的最低位从左侧返回，成为新的最高位。见图 3-13。

`RCL`（带进位循环左移）把目的字节、字或双字操作数中的位左移 1 位，或左移计数操作数指定的位数。它与 `ROL` 的区别在于，把 CF 当作目的操作数最高位之外的一个 1 位扩展。每循环一次，从操作数左侧移出的最高位先进入 CF，再在下一次循环时作为最低位返回操作数。见图 3-14。

`RCR`（带进位循环右移）把目的字节、字或双字操作数中的位右移 1 位，或右移计数操作数指定的位数。它与 `ROR` 的区别在于，把 CF 当作目的操作数最低位之外的一个 1 位扩展。每循环一次，从操作数右侧移出的最低位先进入 CF，再在下一次循环时作为最高位返回操作数。见图 3-15。

### 3.4.4.4 用双精度移位实现快速“BIT BLT”

双精度移位的用途之一，是在位串任意错位的情况下实现位串搬移，称为“bit blt”（BIT BLock Transfer，位块传送）。一个简单例子是把位串从任意偏移处搬移到按双字对齐的字节串中。如果在搬移循环中使用双精度移位，从左到右的位串可以一次搬移 32 位。

```
MOV   ESI,ScrAddr
MOV   EDI,DestAddr
MOV   EBX,WordCnt
MOV   CL,RelOffset      ; 相对偏移 Dest-Src
MOV   EDX,[ESI]         ; 装入源的第一个字
ADD   ESI,4             ; 源地址前进
BltLoop:
LODS                    ; 新的低位部分
SHLD  EDX,EAX,CL        ; EDX 被对齐后的内容覆盖
XCHG  EDX,EAX           ; 交换高/低位部分
STOS                    ; 写出下一个对齐块
DEC   EBX
JA    BltLoop
```

这个循环很简单，却允许以 32 位为单位搬移数据，从而获得尽可能高的性能。没有双精度移位时，最多只能通过 32 位移位并把 `XCHG` 换成 `ROR 16` 来交换寄存器的高低部分，每次循环处理 16 位。比上面更通用的循环，需要在第一个双字（主循环之前）和最后一个双字（主循环之后）上额外做掩码处理，但每次循环仍能像上面的代码一样处理 32 位。

### 3.4.4.5 快速位串插入与提取

双精度移位指令还可以：

- 把寄存器中的位串快速插入内存中一个更大位串的任意位位置，而不扰动插入位两侧的位；
- 从内存中一个更大位串的任意位位置快速提取位串到寄存器，而不扰动被提取位两侧的位。

下面的代码示例说明了各种条件下的位插入与提取。所有示例都假定：字符串数组的基址按双字对齐；位串长度是立即数；位偏移保存在寄存器中。

**1. 位串插入内存（位串长 1–25 位，即跨越不超过 4 字节）**

```
; 把寄存器中右对齐的位串插入内存位串。
; ESI = 待插入的右对齐位串
; EDI = 子串起始位的偏移
; 使用 EAX、ECX
MOV   ECX,EDI           ; 保存原偏移
SHR   EDI,3             ; 偏移除以 8（字节地址）
AND   CL,7H             ; 取出偏移的低 3 位
MOV   EAX,[EDI+strg_base] ; 取包含该字段的双字
ROR   EAX,CL            ; 右对齐旧位域
SHRD  EAX,ESI,length    ; 移入新位
ROL   EAX,length        ; 右对齐新位域
ROL   EAX,CL            ; 移到最终位置
MOV   [EDI+strg_base],EAX ; 写回双字
```

**2. 位串插入内存（位串长 1–31 位，即跨越不超过 5 字节）**

```
MOV   ECX,EDI           ; 暂存偏移
SHR   EDI,5             ; 偏移除以 32（双字地址）
SHL   EDI,2             ; 乘以 4（换算为字节地址）
AND   CL,1FH            ; 取出偏移的低 5 位
MOV   EAX,[EDI+strg_base]   ; 低位双字
MOV   EDX,[EDI+strg_base+4] ; 高位双字
MOV   EBX,EAX
SHRD  EAX,EDX,CL        ; 按双字内偏移右移 EDX:EAX
SHRD  EAX,EBX,CL
SHRD  EAX,ESI,length    ; 移入新位
ROL   EAX,length
MOV   EBX,EAX
SHLD  EAX,EDX,CL        ; 再移回
SHLD  EDX,EBX,CL
MOV   [EDI+strg_base],EAX
MOV   [EDI+strg_base+4],EDX
```

**3. 位串插入内存（位串恰好 32 位）**

```
MOV   EDX,EDI           ; 保存原偏移
SHR   EDI,5
SHL   EDI,2
AND   CL,1FH
MOV   EAX,[EDI+strg_base]
MOV   EDX,[EDI+strg_base+4]
MOV   EBX,EAX
SHRD  EAX,EDX           ; 右移一个双字
SHRD  EDX,EBX
MOV   EAX,ESI           ; 32 位位域就位
MOV   EBX,EAX
SHLD  EAX,EDX
SHLD  EDX,EBX
MOV   [EDI+strg_base],EAX
MOV   [EDI+strg_base+4],EDX
```

**4. 从内存提取位串（位串长 1–25 位）**

```
MOV   ECX,EDI           ; 暂存偏移
SHR   EDI,3             ; 偏移除以 8
AND   CL,7H             ; 取出低 3 位
MOV   EAX,[EDI+strg_base]
SHR   EAX,CL            ; 按双字内偏移右移
AND   EAX,mask          ; 提取出的位域留在 EAX
```

**5. 从内存提取位串（位串长 1–32 位）**

```
MOV   ECX,EDI           ; 暂存偏移
SHR   EDI,5             ; 偏移除以 32
SHL   EDI,2             ; 乘以 4
AND   CL,1FH            ; 取出低 5 位
MOV   EAX,[EDI+strg_base]
MOV   EDX,[EDI+strg_base+4]
SHRD  EAX,EDX,CL        ; 按双字内偏移右移
AND   EAX,mask          ; 提取出的位域留在 EAX
```

## 3.4.5 条件置字节指令

这组指令根据状态标志定义的 16 种条件之一，把字节置为 0 或 1。字节可以在内存中，也可以是一个字节的通用寄存器。这些指令在实现 Pascal 等高级语言中的布尔表达式时特别有用。

`SETcc`（条件 cc 置字节）在条件 cc 为真时把字节置 1，否则置 0。可能条件的定义见附录 D。

## 3.4.6 测试指令

`TEST`（测试）对两个操作数执行逻辑“与”，清零 OF 和 CF，使 AF 未定义，并更新 SF、ZF 和 PF。这些标志可以由条件控制转移指令或条件置字节指令测试。操作数可以是双字、字或字节。

`TEST` 与 `AND` 的区别在于 `TEST` 不改变目的操作数。`TEST` 与 `BT` 的区别在于，`TEST` 适合一次测试多个位的值，而 `BT` 只测试一位。
