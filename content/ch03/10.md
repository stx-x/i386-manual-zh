# 3.10 段寄存器指令

这一类实际上包含几种不同的指令。把它们归在一起，是因为如果系统设计者选择了不分段的存储组织模型，应用程序员就不会用到其中任何一条。与段寄存器有关的指令包括：

1. **段寄存器传送指令**：`MOV SegReg, ...`、`MOV ..., SegReg`、`PUSH SegReg`、`POP SegReg`。
2. **转移到另一个可执行段的控制转移指令**：远直接和远间接 `JMP`、远 `CALL`、远 `RET`。
3. **数据指针指令**：`LDS`、`LES`、`LFS`、`LGS`、`LSS`。

注意，下列与中断有关的指令与此不同：它们都能把控制转移到另一个段，但应用程序员看不到分段的使用。

- `INT n`
- `INTO`
- `BOUND`
- `IRET`

## 3.10.1 段寄存器传送指令

`MOV`、`POP` 和 `PUSH` 也可用于装入和保存段寄存器。这些变体与对应的通用寄存器版本类似，只是其中一个操作数可以是段寄存器。`MOV` 不能把段寄存器传到段寄存器。`POP` 和 `MOV` 都不能把值放入代码段寄存器 CS；只有远控制转移指令才能改变 CS。

## 3.10.2 远控制转移指令

远控制转移指令通过改变 CS 寄存器的内容，把控制转移到另一个段中的位置。

**远直接 JMP**：指定当前代码段之外目标位置的直接 `JMP` 指令含有一个远指针。该指针由新代码段的选择子和新段内的偏移组成。

**远间接 JMP**：指定当前代码段之外目标位置的间接 `JMP` 指令使用一个 48 位变量来指定远指针。

**远 CALL**：段间 `CALL` 把 EIP 和 CS 的值都压入栈。

**远 RET**：段间 `RET` 恢复前一条段间 `CALL` 指令保存在栈上的 CS 和 EIP 值。

## 3.10.3 数据指针指令

数据指针指令把指针（由段选择子和偏移组成）装入一个段寄存器和一个通用寄存器。

`LDS`（用 DS 装入指针）把源操作数中的指针变量传送到 DS 和目的寄存器。源操作数必须是内存操作数，目的操作数必须是通用寄存器。DS 接收指针的段选择子，目的寄存器接收指针的偏移部分，该偏移指向段内某个特定位置。例如：

```
LDS ESI, STRING_X
```

把标识 STRING_X 所在段的选择子装入 DS，并把 STRING_X 的偏移装入 ESI。把 ESI 作为目的操作数，可以方便地为对不在当前数据段中的源串执行串操作做准备。

`LES`（用 ES 装入指针）与 `LDS` 相同，只是由 ES 而不是 DS 接收段选择子。例如：

```
LES EDI, DESTINATION_X
```

把标识 DESTINATION_X 所在段的选择子装入 ES，并把 DESTINATION_X 的偏移装入 EDI。如果期望的位置不在当前附加段中，这条指令可以方便地为串操作选择目的。

`LFS`（用 FS 装入指针）与 `LDS` 相同，只是由 FS 接收段选择子。

`LGS`（用 GS 装入指针）与 `LDS` 相同，只是由 GS 接收段选择子。

`LSS`（用 SS 装入指针）与 `LDS` 相同，只是由 SS 接收段选择子。这条指令尤其重要，因为它能在一次不可中断的操作中改变标识栈的两个寄存器（SS:ESP）。与其他装入 SS 的指令不同，`LSS` 指令结束时不会禁止中断。其他指令（如 `POP SS`）会禁止中断，以便下一条指令装入 ESP，从而形成 SS:ESP 的不可分割装入。由于 `LSS` 可以同时装入 SS 和 ESP，就不必再禁止中断。
