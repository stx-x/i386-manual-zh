# 3.8 标志控制指令

标志控制指令提供了直接改变标志寄存器中某些位状态的方法。

## 3.8.1 进位与方向标志控制指令

进位标志指令与带进位循环移位指令 `RCL`、`RCR` 配合使用很有用。它们可以在执行循环移位之前把进位标志 CF 初始化为已知状态，该循环移位会把进位位送入被循环操作数的一端。

方向标志控制指令专门用于设置或清除方向标志 DF，DF 控制串处理是从左到右还是从右到左。若 DF=0，处理器在每次执行串原语之后自动递增串索引寄存器 ESI 和 EDI；若 DF=1，则递减。程序员在使用串指令的任何过程之前，都应使用这些指令之一，以确保 DF 设置正确。

| 标志控制指令 | 作用 |
|---|---|
| `STC`（置进位标志） | CF := 1 |
| `CLC`（清进位标志） | CF := 0 |
| `CMC`（进位标志求反） | CF := NOT(CF) |
| `CLD`（清方向标志） | DF := 0 |
| `STD`（置方向标志） | DF := 1 |

## 3.8.2 标志传送指令

虽然有专门指令可以改变 CF 和 DF，但没有直接方法改变其他面向应用的标志。标志传送指令允许程序把这些标志传送到栈或 AH 寄存器，再用位操作指令修改它们。

`LAHF` 和 `SAHF` 处理五个状态标志，这些标志主要供算术和逻辑指令使用。

`LAHF`（从标志装入 AH）把 SF、ZF、AF、PF 和 CF 分别复制到 AH 的位 7、6、4、2 和 0（见图 3-22）。其余位（5、3、1）的内容未定义。标志本身不受影响。

`SAHF`（把 AH 存入标志）把 AH 的位 7、6、4、2、0 分别传送到 SF、ZF、AF、PF 和 CF（见图 3-22）。

`PUSHF` 和 `POPF` 不仅可以把标志存入内存以便检查、修改，还可以在执行过程时保存标志寄存器的状态。

`PUSHF`（压入标志）把 ESP 减 2，然后把标志寄存器的低 16 位传送到 ESP 所指的栈顶字（见图 3-23）。变体 `PUSHFD` 把 ESP 减 4，然后把扩展标志寄存器的两个字都传送到 ESP 所指的栈顶（但 VM 和 RF 标志不会被移动）。

`POPF`（弹出标志）把栈顶字中的特定位传送到标志寄存器的低字节（见图 3-23），然后把 ESP 加 2。变体 `POPFD` 把栈顶双字中的特定位传送到扩展标志寄存器（但 RF 和 VM 标志不变），然后把 ESP 加 4。
