# 2.2 数据类型

字节（byte）、字（word）和双字（doubleword）是基本数据类型（见图 2-2）。

- **字节**：从任意逻辑地址开始的 8 个连续位。位编号为 0–7，位 0 是最低有效位。
- **字**：从任意字节地址开始的 2 个连续字节，共 16 位。位编号为 0–15，位 0 是最低有效位。包含字中位 0 的字节称为**低字节**，包含位 15 的字节称为**高字节**。
- **双字**：从任意字节地址开始的 2 个连续字，共 32 位。位编号为 0–31，位 0 是最低有效位。包含双字中位 0 的字称为**低字**，包含位 31 的字称为**高字**。

字中的每个字节都有自己的地址，其中较小的地址就是该字的地址。低地址处的字节包含字的 8 个最低有效位，高地址处的字节包含 8 个最高有效位。双字同理：每个字节各有地址，最小地址即双字的地址，最低地址字节存放 8 个最低有效位，最高地址字节存放 8 个最高有效位。图 2-3 说明了字和双字内部字节的排列方式。

注意，字不必对齐到偶数地址，双字也不必对齐到能被 4 整除的地址。这样，数据结构（例如混有字节、字、双字成员的记录）可以设计得最灵活，存储利用率也最高。在 32 位总线的系统中，处理器与存储器之间的实际数据传送以双字为单位，且从能被 4 整除的地址开始；不过，处理器会把非对齐字或双字的请求转换成存储器接口能接受的一串请求。这种非对齐传送需要额外的存储周期，因而降低性能。为了获得最高性能，设计数据结构（包括栈）时应尽量让字操作数对齐到偶数地址、双字操作数对齐到能被 4 整除的地址。由于 CPU 内部有指令预取和队列，指令本身不要求对齐到字或双字边界（不过，若控制转移的目标地址能被 4 整除，速度会略有提升）。

字节、字和双字是基本的操作数类型，但处理器还支持对这些操作数作其他解释。根据引用该操作数的指令不同，还可识别以下数据类型：

| 类型 | 定义 |
|---|---|
| **整数（Integer）** | 存放在 32 位双字、16 位字或 8 位字节中的有符号二进制数值。所有运算都假定采用 2 的补码表示。符号位分别位于字节的位 7、字的位 15、双字的位 31；正整数符号位为 0，负整数为 1。由于最高位用作符号位，8 位整数的范围是 −128 到 +127；16 位整数为 −32,768 到 +32,767；32 位整数为 −2^(31) 到 +2^(31)−1。数值 0 的符号为正。 |
| **序数（Ordinal）** | 存放在 32 位双字、16 位字或 8 位字节中的无符号二进制数值。所有位都参与数值大小的判定。8 位序数范围 0–255；16 位为 0–65,535；32 位为 0–2^(32)−1。 |
| **近指针（Near Pointer）** | 一个 32 位逻辑地址，即段内偏移。近指针既可用于平坦模型，也可用于分段模型。 |
| **远指针（Far Pointer）** | 由两部分组成的 48 位逻辑地址：16 位段选择子和 32 位偏移。只有当系统设计者选择分段存储组织时，应用程序员才会用到远指针。 |
| **串（String）** | 连续的字节、字或双字序列。串可以包含从 0 到 2^(32)−1 个字节（4 GB）。 |
| **位域（Bit field）** | 连续的位序列，可以从任意字节的任意位开始，最多包含 32 位。 |
| **位串（Bit string）** | 连续的位序列，可以从任意字节的任意位开始，最多包含 2^(32)−1 位。 |
| **BCD** | 十进制数字 0–9 的字节（非压缩）表示。非压缩十进制数按无符号字节量存放，每个字节存一位数字。数值大小由低半字节决定；十六进制值 0–9 有效，并按十进制数字解释。做乘法和除法时高半字节必须为 0；做加法和减法时高半字节可为任意值。 |
| **压缩 BCD（Packed BCD）** | 两个十进制数字（各为 0–9）的字节（压缩）表示，每个半字节存一位数字，高半字节中的数字为最高位。两个半字节中 0–9 均有效。一个压缩十进制字节的范围是 0–99。 |
