# 14.6 实地址模式异常

在实地址模式中执行时，80386 报告某些异常的方式与保护模式不同。表 14-1 详细列出了实地址模式的异常。

| 说明 | 中断号 | 可产生异常的功能 | 返回地址指向出错指令 |
|---|---|---|---|
| 除法错误 | 0 | `DIV`、`IDIV` | 是 |
| 调试异常 | 1 | 所有指令 | 部分指向出错指令，部分指向下一条；处理程序可检查 DR6 判断 |
| 断点 | 3 | `INT` | 否 |
| 溢出 | 4 | `INTO` | 否 |
| 界限检查 | 5 | `BOUND` | 是 |
| 非法操作码 | 6 | 任何未定义操作码，或 `LOCK` 用于不正确的指令 | 是 |
| 协处理器不可用 | 7 | `ESC` 或 `WAIT` | 是 |
| 中断表界限太小 | 8 | `INT` 向量超出 IDTR 界限 | 是 |
| 保留 | 9–12 | | |
| 栈错误 | 12 | 内存操作数跨越偏移 0 或 0FFFFH | 是 |
| 伪保护异常 | 13 | 内存操作数跨越偏移 0FFFFH，或试图执行超过偏移 0FFFFH，或指令长于 15 字节 | 是 |
| 保留 | 14、15 | | |
| 协处理器错误 | 16 | `ESC` 或 `WAIT` | 是 |
| 两字节软件中断 | 0–255 | `INT n` | 否 |

协处理器错误在导致错误的 `ESC` 指令之后的第一条 `ESC` 或 `WAIT` 指令上报告。
