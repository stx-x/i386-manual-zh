# 关于本译本

## 底本

本译本依据 Intel 公司 1986 年出版的《INTEL 80386 PROGRAMMER'S REFERENCE MANUAL》，采用 MIT PDOS 小组存档的 HTML 与 PDF 版本：

- HTML 目录：`https://pdos.csail.mit.edu/6.828/2018/readings/i386/toc.htm`
- PDF：`https://pdos.csail.mit.edu/6.828/2018/readings/i386.pdf`（421 页）

原书章节编号、节标题层级、插图编号、表格编号与原书页码均保留。每节末尾的「原书 p. N」指向 PDF 的印刷页码，旁边给出该节的英文原文链接，便于逐段核对。

## 翻译范围

- **第 1–16 章**：逐段全译，包含正文、列表、表格、图注与代码示例的说明文字。代码本身、寄存器名、指令助记符、操作码、十六进制数与描述符字段名保持原文。
- **第 17 章 17.1–17.2**：全译，包含指令格式、ModR/M 与 SIB 编码、指令参考页的阅读约定与记号说明；编码网格按原书排版保留。
- **第 17 章指令参考（94 条）**：每条给出中文标题与中文说明，操作码表、操作伪代码与三种模式下的异常条件保留英文原文。这样做不是省略，而是因为异常条件中的 `#GP(0)`、`#SS(0)`、`#PF(fault-code)` 等记号与精确措辞需要逐字对照，机器式改写反而有害。中文说明覆盖了每条指令的语义、操作数方向与关键标志影响。
- **附录 A–D**：说明文字、表头与图注翻译；操作码网格、标志交叉引用网格等纯数据表保留原书排版，避免转录错误。

原书中明显的排印错误（如 `MOVSW` 误写为比较字串、`EAS` 误写为寄存器）在译文中按上下文更正，不另作脚注；不影响语义的 OCR 残损（如断开的长句）已按原意补全。

## 翻译原则

1. **忠实优先于流畅**：不增删段落，不把限定条件、例外情况或「必须/可以」的语气译丢。
2. **术语统一**：见[术语对照表](glossary.html)。首次出现用「中文（English）」，之后只用中文；寄存器、指令、操作码、描述符字段名一律保留英文。
3. **保留原书结构**：节号、图号、表号、页码与原文链接一一对应。
4. **技术表述可核对**：涉及特权检查、异常优先级、栈切换等容易译错的段落，尽量保留原文的并列条件与逻辑连接词。

## 技术实现

- **生成器**：`build.py`，零第三方依赖的 Python 静态站点生成器；Markdown 子集 → HTML，自动生成侧边目录、上下章、页码、检索索引与站点地图。
- **检索**：构建时导出 `assets/search.json`，浏览器端做中文二元组（bigram）与英文词混合匹配，无需后端。
- **排版**：自建 CSS。正文衬线、界面无衬线、代码等宽；支持浅色/深色、字号调节、阅读进度、图片放大与打印样式。
- **部署**：`site/` 为纯静态产物，可直接放到 GitHub Pages、Cloudflare Pages 或任意静态服务器。仓库内含 GitHub Actions 工作流。

## 构建

```bash
python3 build.py        # 生成 site/
python3 -m http.server 8000 --directory site
```

翻译源文件位于 `content/`：每章一个目录，每节一个 Markdown 文件，front matter 记录节号、标题、原书页码与锚点。新增或修订一节后重新运行 `build.py` 即可。
