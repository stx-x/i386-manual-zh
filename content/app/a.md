# 附录 A　操作码表

下面的操作码表用于解释 80386 目标代码。用操作码的高 4 位作为行索引，低 4 位作为列索引；若操作码为 0FH，则查两字节操作码表，并用操作码的第二个字节作为该表的行、列索引。

## 缩写记号

操作数用形如 Zz 的两个字符表示：第一个大写字母规定寻址方式，第二个小写字母规定操作数类型。

### 寻址方式代码

| 代码 | 含义 |
|---|---|
| A | 直接地址。指令没有 ModR/M 字节，操作数地址编码在指令中；不能使用基址、变址或比例因子。例如远 `JMP (EA)`。 |
| C | ModR/M 字节的 reg 字段选择控制寄存器。例如 `MOV (0F20, 0F22)`。 |
| D | ModR/M 字节的 reg 字段选择调试寄存器。例如 `MOV (0F21, 0F23)`。 |
| E | 操作码后跟 ModR/M 字节，指定操作数。操作数是通用寄存器或内存地址；若是内存地址，则由段寄存器及基址、变址、比例因子、位移中的任意组合计算。 |
| F | 标志寄存器。 |
| G | ModR/M 字节的 reg 字段选择通用寄存器。例如 `ADD (00)`。 |
| I | 立即数据。操作数的值编码在指令后续字节中。 |
| J | 指令含有加到指令指针上的相对偏移。例如 `JMP short`、`LOOP`。 |
| M | ModR/M 字节只能引用内存。例如 `BOUND`、`LES`、`LDS`、`LSS`、`LFS`、`LGS`。 |
| O | 指令没有 ModR/M 字节，操作数偏移以字或双字编码在指令中（取决于地址大小属性）；不能使用基址、变址或比例因子。例如 `MOV (A0–A3)`。 |
| R | ModR/M 字节的 mod 字段只能引用通用寄存器。例如 `MOV (0F20–0F24, 0F26)`。 |
| S | ModR/M 字节的 reg 字段选择段寄存器。例如 `MOV (8C, 8E)`。 |
| T | ModR/M 字节的 reg 字段选择测试寄存器。例如 `MOV (0F24, 0F26)`。 |
| X | 由 DS:SI 寻址的内存。例如 `MOVS`、`CMPS`、`OUTS`、`LODS`、`SCAS`。 |
| Y | 由 ES:DI 寻址的内存。例如 `MOVS`、`CMPS`、`INS`、`STOS`。 |

### 操作数类型代码

| 代码 | 含义 |
|---|---|
| a | 内存中的两个字操作数或两个双字操作数，取决于操作数大小属性（仅 `BOUND` 使用）。 |
| b | 字节（与操作数大小属性无关）。 |
| c | 字节或字，取决于操作数大小属性。 |
| d | 双字（与操作数大小属性无关）。 |
| p | 32 位或 48 位指针，取决于操作数大小属性。 |
| s | 6 字节伪描述符。 |
| v | 字或双字，取决于操作数大小属性。 |
| w | 字（与操作数大小属性无关）。 |

### 寄存器代码

当操作数是编码在操作码中的特定寄存器时，用寄存器名标识，例如 AX、CL 或 ESI。寄存器名表明其宽度是 32、16 还是 8 位。形如 eXX 的寄存器标识用于宽度取决于操作数大小属性的场合；例如 eAX 表示操作数大小属性为 16 时使用 AX，为 32 时使用 EAX。
