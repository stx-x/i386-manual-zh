# 附录 D　条件码

::: note
“高于（above）”和“低于（below）”指两个无符号值之间的关系（不测试 SF 和 OF）；“大于（greater）”和“小于（less）”指两个有符号值之间的关系（测试 SF 和 OF）。
:::

## 条件的定义

（用于条件指令 `Jcc` 和 `SETcc`）

| 助记符 | 含义 | 指令子码 | 测试条件 |
|---|---|---|---|
| O | 溢出 | 0000 | OF = 1 |
| NO | 无溢出 | 0001 | OF = 0 |
| B / NAE | 低于 / 不高于且不等于 | 0010 | CF = 1 |
| NB / AE | 不低于 / 高于或等于 | 0011 | CF = 0 |
| E / Z | 相等 / 为零 | 0100 | ZF = 1 |
| NE / NZ | 不相等 / 不为零 | 0101 | ZF = 0 |
| BE / NA | 低于或等于 / 不高于 | 0110 | (CF 或 ZF) = 1 |
| NBE / A | 不低于且不等于 / 高于 | 0111 | (CF 或 ZF) = 0 |
| S | 有符号（负） | 1000 | SF = 1 |
| NS | 无符号（非负） | 1001 | SF = 0 |
| P / PE | 有奇偶性 / 奇偶性为偶 | 1010 | PF = 1 |
| NP / PO | 无奇偶性 / 奇偶性为奇 | 1011 | PF = 0 |
| L / NGE | 小于 / 不大于且不等于 | 1100 | (SF 异或 OF) = 1 |
| NL / GE | 不小于 / 大于或等于 | 1101 | (SF 异或 OF) = 0 |
| LE / NG | 小于或等于 / 不大于 | 1110 | ((SF 异或 OF) 或 ZF) = 1 |
| NLE / G | 不小于且不等于 / 大于 | 1111 | ((SF 异或 OF) 或 ZF) = 0 |
