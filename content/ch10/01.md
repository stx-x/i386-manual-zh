# 10.1 复位后的处理器状态

EAX 的内容取决于上电自检的结果。自检可以通过在 RESET 结束时断言 BUSY# 从外部请求。若 80386 通过自检，EAX 寄存器为零；自检后 EAX 中的非零值表明该 80386 单元有故障。若未请求自检，RESET 后 EAX 的内容未定义。

如图 10-1 所示，RESET 后 DX 含有部件标识和版本号。DH 为 3，表示 80386 部件；DL 含有版本级别的唯一标识。

控制寄存器零（CR0）含有图 10-2 所示的值。若配置中存在 80387（根据 RESET 后 ERROR# 引脚的状态判断），则置位 CR0 的 ET 位。若 ET 复位，配置中要么有 80287，要么没有协处理器；需要通过软件测试来区分后两种可能。

其余寄存器和标志设置如下：

```
EFLAGS        = 00000002H
IP            = 0000FFF0H
CS 选择子     = 0000H
DS 选择子     = 0000H
ES 选择子     = 0000H
SS 选择子     = 0000H
FS 选择子     = 0000H
GS 选择子     = 0000H
IDTR: 基址    = 0
      界限    = 03FFH
```

未提及的所有寄存器均未定义。

这些设置意味着处理器以实地址模式启动，且中断被禁止。
