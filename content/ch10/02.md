# 10.2 实地址模式的软件初始化

在实地址模式下，程序必须先初始化少数几个结构，才能利用该模式提供的全部特性。

## 10.2.1 栈

在装入栈段寄存器（SS）之前，不能使用任何依赖栈的指令。SS 必须指向 RAM 中的一块区域。

## 10.2.2 中断表

80386 的初始状态使中断处于禁止状态；不过，若发生异常或不可屏蔽中断（NMI），处理器仍会试图访问中断表。初始化软件应采取以下措施之一：

- 把 IDTR 中的界限值改为零。这样，若发生异常或不可屏蔽中断，就会关机（shutdown）。（关机如何在外部信号，见《80386 Hardware Reference Manual》。）
- 在中断表中可能被异常或中断使用的所有位置，放入指向有效中断处理程序的指针。
- 修改 IDTR，使其指向有效的中断表。

## 10.2.3 最初的指令

RESET 之后，取指时地址线 A{31–20} 自动置高。这一事实连同 CS:IP 的初值，使指令执行从物理地址 FFFFFFF0H 开始。可以用近（段内）控制转移指令把控制传到地址空间顶部 64K 内的其他地址。第一条远（段间）`JMP` 或 `CALL` 指令使 A{31–20} 变低，80386 继续在物理内存低 1 MB 中执行指令。地址线 A{31–20} 的这种自动置高，使系统设计者可以在地址空间高端使用 ROM 来初始化系统。
