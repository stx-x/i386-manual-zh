# 9.1 中断的识别

处理器为每一类中断或异常关联一个标识号。

NMI 以及处理器识别的异常被赋予 0–31 范围内的预定标识号。这个范围内的编号并非目前都被 80386 使用；未分配的编号由 Intel 保留，供将来扩展。

可屏蔽中断的标识号由外部中断控制器（如 Intel 8259A 可编程中断控制器）确定，并在处理器的中断应答序列中传送给处理器。8259A PIC 分配的编号可由软件指定，32–255 范围内的任何编号都可以使用。表 9-1 给出了中断与异常标识号的分配。

根据报告方式以及是否支持重新执行导致异常的指令，异常分为故障（fault）、陷阱（trap）和中止（abort）。

**故障**是在导致异常的指令“之前”报告的异常。故障要么在指令开始执行之前检测到，要么在指令执行期间检测到。若在执行期间检测到，报告故障时机器已恢复到允许重新执行该指令的状态。

**陷阱**是在检测到异常的指令之后、紧接的指令边界处报告的异常。

**中止**既不精确定位导致异常的指令，也不允许重新执行导致异常的程序。中止用于报告严重错误，如硬件错误以及系统表中不一致或非法的值。

| 标识号 | 说明 |
|---|---|
| 0 | 除法错误 |
| 1 | 调试异常 |
| 2 | 不可屏蔽中断（NMI） |
| 3 | 断点（单字节 `INT 3` 指令） |
| 4 | 溢出（`INTO` 指令） |
| 5 | 界限检查（`BOUND` 指令） |
| 6 | 非法操作码 |
| 7 | 协处理器不可用 |
| 8 | 双重故障 |
| 9 | 保留 |
| 10 | 非法 TSS |
| 11 | 段不存在 |
| 12 | 栈异常 |
| 13 | 通用保护 |
| 14 | 页错误 |
| 15 | 保留 |
| 16 | 协处理器错误 |
| 17–31 | 保留 |
| 32–255 | 可供通过 INTR 引脚的外部中断使用 |
