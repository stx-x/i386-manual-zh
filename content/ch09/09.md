# 9.9 异常汇总

表 9-6 汇总了 386 识别的异常。

| 说明 | 中断号 | 返回地址指向出错指令 | 异常类型 | 可产生异常的功能 |
|---|---|---|---|---|
| 除法错误 | 0 | 是 | 故障 | `DIV`、`IDIV` |
| 调试异常 | 1 | — | 故障/陷阱 | 任何指令。有些是陷阱，有些是故障，处理程序可检查 DR6 判断（见第 12 章） |
| 断点 | 3 | 否 | 陷阱 | 单字节 `INT 3` |
| 溢出 | 4 | 否 | 陷阱 | `INTO` |
| 界限检查 | 5 | 是 | 故障 | `BOUND` |
| 非法操作码 | 6 | 是 | 故障 | 任何非法指令 |
| 协处理器不可用 | 7 | 是 | 故障 | `ESC`、`WAIT` |
| 双重故障 | 8 | 是 | 中止 | 任何可产生异常的指令 |
| 协处理器段越界 | 9 | 否 | 中止 | `ESC` 指令中跨越段末尾的操作数 |
| 非法 TSS | 10 | 是 | 故障 | `JMP`、`CALL`、`IRET`、任何中断。若在处理外部中断期间发生，则不可重新执行 |
| 段不存在 | 11 | 是 | 故障 | 任何修改段寄存器的指令 |
| 栈异常 | 12 | 是 | 故障 | 任何经 SS 的内存引用 |
| 通用保护 | 13 | 是 | 故障/中止 | 任何内存引用或取指。所有 GP 故障都可重新执行；若在试图向量到外部中断处理程序时发生，被中断程序可重新执行，但中断可能丢失 |
| 页错误 | 14 | 是 | 故障 | 任何内存引用或取指 |
| 协处理器错误 | 16 | 是 | 故障 | `ESC`、`WAIT`。协处理器错误在导致错误的 `ESC` 之后执行的第一条 `ESC` 或 `WAIT` 指令上作为故障报告 |
| 两字节软件中断 | 0–255 | 否 | 陷阱 | `INT n` |
