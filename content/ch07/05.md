# 7.5 任务切换

80386 在以下四种情况下把执行切换到另一个任务：

1. 当前任务执行引用 TSS 描述符的 `JMP` 或 `CALL`；
2. 当前任务执行引用任务门的 `JMP` 或 `CALL`；
3. 中断或异常向量指向 IDT 中的任务门；
4. 当前任务在 NT 标志置位时执行 `IRET`。

`JMP`、`CALL`、`IRET`、中断和异常都是 80386 的普通机制，也可以用于不需要任务切换的场合。所引用描述符的类型，或标志字中的 NT（嵌套任务）位，区分了标准机制与引发任务切换的变体。

为引发任务切换，`JMP` 或 `CALL` 可以引用 TSS 描述符或任务门，两种情况下效果相同：80386 切换到指定任务。

当中断或异常的向量指向 IDT 中的任务门时，会引发任务切换；若指向中断门或陷阱门，则不发生切换。中断机制的更多信息见第 9 章。

中断处理程序无论是作为独立任务被调用，还是作为被中断任务中的一个过程被调用，最终都会把控制交回被中断任务中的被中断过程。不过，若 NT 标志置位，处理程序就是一个中断任务，`IRET` 会切换回被中断的任务。

任务切换操作包括以下步骤：

1. **检查当前任务是否有权切换到指定任务**。对 `JMP` 或 `CALL` 指令，适用数据访问特权规则：TSS 描述符或任务门的 DPL 必须在数值上大于或等于 CPL 与门选择子 RPL 中的较大者（即特权更低）。无论目标任务门或 TSS 描述符的 DPL 如何，异常、中断和 `IRET` 都允许切换任务。
2. **检查新任务的 TSS 描述符已标记存在且界限有效**。到此为止的任何错误都发生在即将离开的任务的上下文中；这些错误可重新开始，并能以对应用程序透明的方式处理。
3. **保存当前任务的状态**。处理器从任务寄存器中取出当前 TSS 的基地址，据此定位，然后把寄存器复制到当前 TSS：EAX、ECX、EDX、EBX、ESP、EBP、ESI、EDI、ES、CS、SS、DS、FS、GS 以及标志寄存器。TSS 的 EIP 字段指向导致任务切换的那条指令之后的指令。
4. **把新任务 TSS 描述符的选择子装入任务寄存器**，把新任务的 TSS 描述符标记为忙，并置位 MSW 的 TS（任务已切换）位。该选择子要么是控制转移指令的操作数，要么取自任务门。
5. **从新任务的 TSS 装入其状态并恢复执行**。装入的寄存器包括：LDT 寄存器、标志寄存器、通用寄存器 EIP、EAX、ECX、EDX、EBX、ESP、EBP、ESI、EDI，段寄存器 ES、CS、SS、DS、FS、GS，以及 PDBR。此步骤中检测到的任何错误都发生在新任务的上下文中；对异常处理程序来说，新任务的第一条指令尚未执行。

注意，任务切换发生时，即将离开的任务的状态总会被保存。若该任务恢复执行，将从导致任务切换的指令之后开始，寄存器恢复为任务停止执行时的值。

每次任务切换都会置位 MSW（机器状态字）中的 TS 位。当系统中有协处理器（如数值协处理器）时，TS 标志对系统软件有用；它表明协处理器的上下文可能不与当前 80386 任务对应。TS 位与协处理器的详细讨论见第 11 章。

若异常处理程序要在新任务中处理任务切换异常（表 7-1 中第 4 至 16 项检查引起的异常），应谨慎对待任何可能装入导致异常的选择子的动作。除非处理程序先检查该选择子并修复潜在问题，否则这种动作很可能引发另一个异常。

新任务恢复执行时的特权级，既不受即将离开任务特权级的限制，也不受其影响。由于任务由各自的地址空间和 TSS 隔离，且特权规则可以防止对 TSS 的不当访问，因此不需要用特权规则约束任务 CPL 之间的关系。新任务从 TSS 装入的 CS 选择子 RPL 所指示的特权级开始执行。

| 检查项 | 检查说明 | 异常 | 错误码选择子 |
|---|---|---|---|
| 1 | 新任务 TSS 描述符存在 | NP | 新任务 TSS |
| 2 | 新任务 TSS 描述符标记为非忙 | GP | 新任务 TSS |
| 3 | 新任务 TSS 的界限 ≥ 103 | TS | 新任务 TSS |
| — | **以下开始装入所有寄存器和选择子值** | | |
| 4 | 新任务的 LDT 选择子有效 | TS | 新任务 TSS |
| 5 | 新任务的 LDT 存在 | TS | 新任务 TSS |
| 6 | CS 选择子有效 | TS | 代码段 |
| 7 | 代码段存在 | NP | 代码段 |
| 8 | 代码段 DPL 与 CS 的 RPL 匹配 | TS | 代码段 |
| 9 | 栈段选择子有效 | GP | 栈段 |
| 10 | 栈段存在 | SF | 栈段 |
| 11 | 栈段 DPL = CPL | SF | 栈段 |
| 12 | 栈选择子 RPL = CPL | GP | 栈段 |
| 13 | DS、ES、FS、GS 选择子有效 | GP | 段 |
| 14 | DS、ES、FS、GS 段可读 | GP | 段 |
| 15 | DS、ES、FS、GS 段存在 | NP | 段 |
| 16 | DS、ES、FS、GS 段 DPL ≥ CPL（一致段除外） | GP | 段 |

NP = 段不存在异常，GP = 通用保护错误，TS = 非法 TSS，SF = 栈错误。

选择子有效性检查包括：选择子位于正确的表（例如 LDT 选择子应指向 GDT）、在表界限内，并引用正确类型的描述符（例如 LDT 选择子引用 LDT 描述符）。
