# 17.2 指令格式

所有指令编码都是图 17-1 所示通用指令格式的子集。指令由可选前缀、一或两个主操作码字节、可能有的地址说明符（ModR/M 字节与 SIB 字节）、按需出现的位移，以及按需出现的立即数据字段组成。

主操作码中可以定义更小的编码字段，用于说明操作方向、位移大小、寄存器编码或符号扩展；编码字段因操作类别而异。

大多数可以引用内存操作数的指令，在主操作码字节之后都有一个寻址形式字节。这个字节称为 **ModR/M 字节**，规定要使用的地址形式。ModR/M 字节的某些编码会指示第二个寻址字节，即 **SIB（比例、变址、基址）字节**，它跟在 ModR/M 字节之后，用于完整说明寻址形式。

寻址形式可以包含紧跟在 ModR/M 或 SIB 字节之后的位移。位移可以是 8 位、16 位或 32 位。

若指令指定立即操作数，立即操作数总是跟在所有位移字节之后，并且总是指令的最后一个字段。

允许的指令前缀代码如下：

```
F3H    REP 前缀（只与串指令配合）
F3H    REPE/REPZ 前缀（只与串指令配合）
F2H    REPNE/REPNZ 前缀（只与串指令配合）
F0H    LOCK 前缀
```

段超越前缀如下：

```
2EH    CS 段超越前缀
36H    SS 段超越前缀
3EH    DS 段超越前缀
26H    ES 段超越前缀
64H    FS 段超越前缀
65H    GS 段超越前缀
66H    操作数大小超越
67H    地址大小超越
```

## 17.2.1 ModR/M 与 SIB 字节

在许多 80386 指令中，ModR/M 和 SIB 字节跟在操作码字节之后，含有以下信息：

- 指令中使用的索引类型或寄存器号；
- 要使用的寄存器，或用于选择指令的更多信息；
- 基址、变址和比例信息。

ModR/M 字节含有三个字段：

- **mod 字段**占字节最高两位，与 r/m 字段组合形成 32 种可能值：8 个寄存器和 24 种寻址方式；
- **reg 字段**占 mod 之后的 3 位，指定寄存器号或操作码的另外 3 位信息，其含义由指令的第一个（操作码）字节决定；
- **r/m 字段**占最低 3 位，可以指定寄存器作为操作数位置，也可以与 mod 字段组合构成寻址方式编码的一部分。

32 位寻址的基址变址形式和比例变址形式需要 SIB 字节；ModR/M 字节的某些编码指示 SIB 字节存在。SIB 字节包含：

- **ss 字段**占最高两位，指定比例因子；
- **index 字段**占随后 3 位，指定变址寄存器的编号；
- **base 字段**占最低 3 位，指定基址寄存器的编号。

## 17.2.2 如何阅读指令参考页

本章每条 80386 指令说明都采用以下格式，以 `CMC` 为例：

```
Opcode   Instruction    Clocks   Description
F5       CMC            2        Complement carry flag
```

上表之后是标为“Operation（操作）”“Description（说明）”“Flags Affected（影响的标志）”“Protected Mode Exceptions（保护模式异常）”“Real Address Mode Exceptions（实地址模式异常）”，以及可选的“Notes（注意）”的段落。下面解释这些段落中使用的记号与缩写。

### 17.2.2.1 操作码

“Opcode”列给出指令每种形式产生的完整目标代码。尽可能按字节在内存中出现的顺序以十六进制给出。十六进制字节以外的条目定义如下：

| 记号 | 含义 |
|---|---|
| `/digit` | digit 为 0–7，表示指令的 ModR/M 字节只使用 r/m 操作数；reg 字段含有该数字，作为操作码的扩展。 |
| `/r` | 表示 ModR/M 字节同时含有寄存器操作数和 r/m 操作数。 |
| `cb`、`cw`、`cd`、`cp` | 跟在操作码之后的 1、2、4、6 字节值，用于指定代码偏移，可能还指定代码段寄存器的新值。 |
| `ib`、`iw`、`id` | 跟在操作码、ModR/M 字节或比例变址字节之后的 1、2、4 字节立即操作数。操作码决定它是否为有符号值；所有字和双字均低字节在前。 |
| `+rb`、`+rw`、`+rd` | 0–7 的寄存器码，加到加号左侧的十六进制字节上，形成单个操作码字节。 |

```
      rb         rw         rd
    AL = 0     AX = 0     EAX = 0
    CL = 1     CX = 1     ECX = 1
    DL = 2     DX = 2     EDX = 2
    BL = 3     BX = 3     EBX = 3
    AH = 4     SP = 4     ESP = 4
    CH = 5     BP = 5     EBP = 5
    DH = 6     SI = 6     ESI = 6
    BH = 7     DI = 7     EDI = 7
```

### 17.2.2.2 指令

“Instruction”列给出指令语句在 ASM386 程序中的语法。指令语句中表示操作数的符号如下：

| 符号 | 含义 |
|---|---|
| `rel8` | 相对地址，范围从指令结束前 128 字节到指令结束后 127 字节。 |
| `rel16`、`rel32` | 与指令汇编在同一代码段内的相对地址。`rel16` 用于操作数大小属性为 16 位的指令，`rel32` 用于 32 位。 |
| `ptr16:16`、`ptr16:32` | 远指针，通常位于与指令不同的代码段。冒号右侧的值是送往代码段寄存器的 16 位选择子或值，左侧是目的段内的偏移。`ptr16:16` 用于 16 位操作数大小属性，`ptr16:32` 用于 32 位。 |
| `r8` | 字节寄存器 AL、CL、DL、BL、AH、CH、DH、BH 之一。 |
| `r16` | 字寄存器 AX、CX、DX、BX、SP、BP、SI、DI 之一。 |
| `r32` | 双字寄存器 EAX、ECX、EDX、EBX、ESP、EBP、ESI、EDI 之一。 |
| `imm8` | 立即字节值，为 −128 到 +127 的有符号数。若与字或双字操作数结合，会符号扩展。 |
| `imm16` | 立即字值，用于 16 位操作数大小属性，范围 −32768 到 +32767。 |
| `imm32` | 立即双字值，用于 32 位操作数大小属性，范围 +2147483647 到 −2147483648。 |
| `r/m8` | 一个字节操作数，可以是字节寄存器（AL、BL、CL、DL、AH、BH、CH、DH）的内容，或内存中的字节。 |
| `r/m16` | 字寄存器或内存操作数，用于 16 位操作数大小属性。字寄存器为 AX、BX、CX、DX、SP、BP、SI、DI；内存内容在有效地址计算给出的地址处。 |
| `r/m32` | 双字寄存器或内存操作数，用于 32 位操作数大小属性。双字寄存器为 EAX、EBX、ECX、EDX、ESP、EBP、ESI、EDI。 |
| `m8`、`m16`、`m32` | 由 DS:SI 或 ES:DI 寻址的内存字节、字或双字（仅用于串指令）。 |
| `m16:16`、`m16:32` | 含有两个数组成的远指针的内存操作数：冒号左侧是段选择子，右侧是偏移。 |
| `m16&32`、`m16&16`、`m32&32` | 由和号两侧指明大小的数据项对组成的内存操作数。`m16&16`、`m32&32` 供 `BOUND` 提供数组索引上下界；`m16&32` 供 `LIDT`、`LGDT` 装入界限字和基址双字。 |
| `moffs8`、`moffs16`、`moffs32` | 内存偏移：某些 `MOV` 变体使用的简单字节、字或双字内存变量。实际地址是相对于段基址的简单偏移，指令中不使用 ModR/M 字节。数字表示其大小，由指令的地址大小属性决定。 |
| `Sreg` | 段寄存器。编码为 ES=0、CS=1、SS=2、DS=3、FS=4、GS=5。 |

### 17.2.2.3 时钟数

“Clocks”列给出指令执行所需的时钟周期数，计算基于以下假设：

- 指令已预取并译码，可以执行；
- 总线周期不需要等待状态；
- 没有本地总线 HOLD 请求延迟处理器访问总线；
- 指令执行期间不检测异常；
- 内存操作数已对齐。

带 r/m（寄存器或内存）操作数的指令，时钟数用斜杠分隔：左侧用于寄存器操作数，右侧用于内存操作数。

时钟数说明中使用以下符号：

- `n`：重复次数；
- `m`：下一条执行指令的组成部分数，整个位移（若有）算一个组成部分，整个立即数据（若有）算一个组成部分，指令的其余每个字节及前缀各算一个组成部分；
- `pm=`：指令在保护模式中执行时的时钟数。保护模式与实地址模式时钟数相同时不给出 `pm=`。

若指令执行期间发生异常且异常处理程序在另一个任务中，指令执行时间要加上任务切换的时钟数。该参数取决于：当前任务所用 TSS 类型（386 或 286）、新任务所用 TSS 类型、当前任务是否在 V86 模式、新任务是否在 V86 模式。表 17-5 汇总了异常导致的任务切换时间。

| 原任务 | 新任务 386 TSS（VM=0） | 新任务 286 TSS |
|---|---|---|
| 386 TSS，VM=0 | 309 | 282 |
| 386 TSS，VM=1 | 314 | 231 |
| 286 TSS | 307 | 282 |

### 17.2.2.4 说明

“Clocks”列之后的“Description”列简要解释指令的各种形式；“Operation”和“Description”节给出指令操作的更多细节。

### 17.2.2.5 操作

“Operation”节用类似 Algol 或 Pascal 的记号给出指令的算法性描述，由以下元素组成：

- 注释括在“(*”与“*)”之间；
- 复合语句括在 `IF`/`THEN`/`ELSE`/`FI`、`DO`/`OD` 或 `CASE ... OF`/`ESAC` 关键字之间；
- 寄存器名表示寄存器的内容；寄存器名加方括号表示该寄存器所含地址处的内容。例如 `ES:[DI]` 表示 ES 段内偏移在 DI 中的位置的内容；`[SI]` 表示 SI 所含地址处相对于默认段 DS 或超越段的内容；
- 方括号也用于内存操作数，表示内存位置的内容是段相对偏移。例如 `[SRC]` 表示源操作数的内容是段相对偏移；
- `A := B;` 表示把 B 的值赋给 A；
- `=`、`<>`、`>=`、`<=` 是关系运算符，分别表示等于、不等于、大于或等于、小于或等于。

算法描述中使用以下标识符：

- `OperandSize` 表示指令的操作数大小属性（16 或 32 位）；`AddressSize` 表示地址大小属性。例如，`IF instruction = CMPSW THEN OperandSize := 16; ELSE IF instruction = CMPSD THEN OperandSize := 32; FI; FI;` 表示操作数大小属性取决于所用的 `CMPS` 形式。
- `StackAddrSize` 表示与指令关联的栈地址大小属性，值为 16 或 32 位。
- `SRC` 表示源操作数；有两个操作数时，它是右侧那个。
- `DEST` 表示目的操作数；有两个操作数时，它是左侧那个。
- `LeftSRC`、`RightSRC` 在两个操作数都是源时区分它们。
- `eSP` 表示 SP 或 ESP，取决于当前栈段 B 位的设置。

使用以下函数：

- `Truncate to 16 bits(value)`：丢弃最高位，把值缩小到 16 位。
- `Addr(operand)`：返回操作数的有效地址（加段基址之前的有效地址计算结果）。
- `ZeroExtend(value)`：把值零扩展到指令的操作数大小属性。例如 `OperandSize=32` 时，字节值 −10（F6H）扩展为 000000F6H。
- `SignExtend(value)`：把值符号扩展到指令的操作数大小属性。例如 `OperandSize=32` 时，字节值 −10（F6H）扩展为 FFFFFFF6H。
- `Push(value)`：把值压栈，压入字节数由操作数大小属性决定。若 `StackAddrSize=16` 且 `OperandSize=16`，则 SP := SP−2，SS:[SP] := value；若 `OperandSize=32`，则 SP := SP−4。`StackAddrSize=32` 时使用 ESP 同理。
- `Pop()`：从栈顶取出值并返回，返回字还是双字取决于操作数大小属性。
- `Bit[BitBase, BitOffset]`：返回位串中某一位的地址。位在寄存器和内存字节内从低位到高位编号。基操作数为寄存器时，偏移范围 0–31；为内存地址时，偏移范围约为 ±2 G 位，所寻址的位是地址 (BitBase + (BitOffset DIV 8)) 处字节内的第 (Offset MOD 8) 位，其中 DIV 是向负无穷舍入的有符号除法，MOD 返回正数。
- `I-O-Permission(I-O-Address, width)`：根据 I/O 许可位图等返回 TRUE 或 FALSE。
- `Switch-Tasks`：第 7 章描述的任务切换函数。
