# 12.2 调试寄存器

80386 用六个寄存器控制调试特性。这些寄存器通过 `MOV` 指令的变体访问，调试寄存器既可作为源操作数，也可作为目的操作数。调试寄存器是特权资源；访问它们的 `MOV` 指令只能在特权级 0 执行，在其他任何特权级读写调试寄存器都会导致通用保护异常。图 12-1 给出了调试寄存器的格式。

## 12.2.1 调试地址寄存器（DR0–DR3）

这些寄存器各自含有一个与四个断点条件之一关联的线性地址。每个断点条件由 DR7 中的位进一步定义。

无论是否启用分页，调试地址寄存器都有效。这些寄存器中的地址是线性地址：若启用分页，处理器通过分页机制把线性地址转换为物理地址（见第 5 章）；若未启用分页，这些线性地址就是物理地址。

注意，启用分页时，不同任务可以有不同的线性到物理地址映射。此时，调试地址寄存器中的某个地址可能只对一个任务有意义，对另一个任务没有意义。因此，80386 在 DR7 中同时提供全局和局部启用位，指示给定调试地址具有全局（所有任务）还是局部（仅当前任务）相关性。

## 12.2.2 调试控制寄存器（DR7）

图 12-1 所示的调试控制寄存器既帮助定义调试条件，也用于有选择地启用和禁用这些条件。

对于 DR0–DR3 中的每个地址，相应字段 R/W0–R/W3 规定应引发断点的动作类型。处理器对这些位的解释如下：

- 00——仅在执行指令时断点；
- 01——仅在写数据时断点；
- 10——未定义；
- 11——在读或写数据时断点，但取指不断点。

字段 LEN0–LEN3 规定要监视的数据项长度，可以指定 1、2 或 4 字节。长度字段的解释如下：

- 00——1 字节；
- 01——2 字节；
- 10——未定义；
- 11——4 字节。

若 RWn 为 00（执行指令），则 LENn 也应为 00；其他长度未定义。

DR7 的低 8 位（L0–L3 和 G0–G3）有选择地启用四个地址断点条件。启用分两个层次：局部（L0–L3）和全局（G0–G3）。局部启用位在每次任务切换时由处理器自动复位，以免新任务中出现不需要的断点条件；全局启用位不因任务切换而复位，因此可用于对所有任务都成立的条件。

LE 和 GE 位控制处理器的“精确数据断点匹配”特性。若 LE 或 GE 之一置位，处理器会放慢执行，使数据断点在导致它的那条指令上报告。建议在设置数据断点时置位其中之一。处理器在任务切换时清除 LE，但不清除 GE。

## 12.2.3 调试状态寄存器（DR6）

图 12-1 所示的调试状态寄存器使调试器能判断发生了哪些调试条件。

当处理器检测到已启用的调试异常时，它在进入调试异常处理程序之前置位该寄存器的低位（B0–B3）。若 DRn、LENn 和 R/Wn 描述的条件发生，则置位 Bn。（注意，无论 Gn 或 Ln 是否置位，处理器都会置位 Bn。若同时发生多个断点条件，且断点陷阱是因 n 之外的某个已启用条件而发生，Bn 仍可能置位，即使 Gn 和 Ln 都未置位。）

BT 位与 TSS 的 T 位（调试陷阱位）相关联（T 位的位置见第 7 章）。若发生了任务切换且新 TSS 的 T 位置位，处理器在进入调试处理程序之前置位 BT 位。DR7 中没有对应的位来启用或禁用该陷阱；TSS 的 T 位是唯一的启用位。

BS 位与 EFLAGS 寄存器的 TF（陷阱标志）位相关联。若调试处理程序因发生单步异常而进入，则置位 BS。单步陷阱是优先级最高的调试异常；因此，当 BS 置位时，其他调试状态位也可能同时置位。

若下一条指令将读写八个调试寄存器之一，而 ICE-386 同时也在使用调试寄存器，则置位 BD 位。

注意，处理器从不清除 DR6 的位。为避免在识别下一次调试异常时产生混淆，调试处理程序应在返回前立即向 DR6 写入 0。

## 12.2.4 断点字段的识别

四个断点条件各自的线性地址和 LEN 字段，为数据断点定义了一个连续字节地址范围。LEN 字段可以指定 1、2 或 4 字节字段。2 字节字段必须对齐到字边界（地址为 2 的倍数），4 字节字段必须对齐到双字边界（地址为 4 的倍数）。处理器会强制执行这些要求：它用 LEN 位屏蔽调试地址寄存器中地址的低位。未正确对齐的代码或数据断点地址不会产生预期结果。

若一次内存访问涉及的任何一个字节落在断点地址寄存器与相应 LEN 字段定义的范围内，就触发数据读/写断点。表 12-1 给出了一些断点字段以及会/不会导致陷阱的内存引用示例。

要为长度超过 1 字节的非对齐字段设置数据断点，可以在断点寄存器中放置两组表项，使每组正确对齐，且两组合起来覆盖该字段长度。

指令断点地址的长度必须指定为 1 字节（LEN=00），其他值未定义。只有当地址指向指令的第一个字节时，处理器才识别指令断点；若指令带有前缀，断点地址必须指向第一个前缀。

|---|---|---|
| DR0 | 0A0001 | 1（LEN0=00） |
| DR1 | 0A0002 | 1（LEN1=00） |
| DR2 | 0B0002 | 2（LEN2=01） |
| DR3 | 0C0000 | 4（LEN3=11） |
