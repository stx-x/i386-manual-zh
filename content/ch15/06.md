# 15.6 与 8086 的差异

一般来说，V86 模式能正确执行为 8086、8088、80186 和 80188 编写的软件。以下差异与 14.7 节列出的基本相同的项目不再重复展开，只说明 V86 模式特有的部分；未列出的项目（时钟数、除法异常指向、未定义操作码、`PUSH SP`、移位计数、冗余前缀、跨偏移操作数、顺序执行越界、`LOCK` 限制、单步优先级、`IDIV` 商、NMI 屏蔽、协处理器向量与中断控制器）与 14.7 节一致。

1. **栈中的标志**。`PUSHF`、中断和异常保存的标志在位 12–15 上的设置与 8086 不同。8086 把这些位存为 1；V86 模式中位 15 总是 0，位 14–12 反映最后一次装入它们的值。
2. **数值异常处理程序应允许前缀**。80386 为协处理器异常保存的 CS:IP 指向 `ESC` 指令之前的任何前缀；8086/8088 保存的 CS:IP 指向 `ESC` 指令本身。
3. **协处理器错误向量到中断 16**。带协处理器的 80386 系统必须用中断向量 16 处理协处理器错误；若 8086 系统用其他向量处理 8087 中断，两个向量都应指向该处理程序。
4. **协处理器不使用中断控制器**。协处理器发给 80386 的错误信号不经过中断控制器（8087 的 INT 信号则经过），处理程序中涉及中断控制器的指令可能需要删除。
5. **`LOCK` 受限**。`LOCK` 前缀及其输出信号只应用于阻止其他总线主控中断数据搬移。80386 在引用内存的 `XCHG` 期间总是断言 LOCK（即使未使用前缀）。`LOCK` 只能与 `BTS`、`BTR`、`BTC`、`XCHG`、`ADD`、`ADC`、`SUB`、`SBB`、`INC`、`DEC`、`AND`、`OR`、`XOR`、`NOT`、`NEG` 在更新内存时配合使用；在其他指令前使用会产生未定义操作码异常（中断 6）。
6. **单步执行外部中断处理程序**。80386 单步异常的优先级高于 8086/8088，防止程序单步执行期间发生的外部中断去单步执行其中断处理程序；由 `INT` 指令或异常调用的处理程序仍会被单步执行。
7. **`IDIV` 商为 80H 或 8000H**。80386 可以产生最大负数作为商，8086/8088 则产生异常 0。
8. **操作数跨越偏移 0 或 65535**。80386 会引发异常：数据段用异常 13，栈段用异常 12；8086 则按模 65536 环绕。
9. **顺序执行跨越偏移 65535**。8086 从同一段偏移 0 继续取指；80386 产生异常 13。
10. **`PUSH SP` 的值**。80386 压入 SP 递增之前的值，8086/8088 压入递增之后的值。若压入值重要，可用 `PUSH BP`、`MOV BP, SP`、`XCHG BP, [BP]` 三条指令替代。
