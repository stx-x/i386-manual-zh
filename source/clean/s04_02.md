# 4.2  Systems Instructions

Systems instructions deal with such functions as:

1. Verification of pointer parameters (refer to Chapter 6):

2. ARPL> -- Adjust RPL

3. LAR -- Load Access Rights

4. LSL -- Load Segment Limit

5. VERR -- Verify for Reading

6. VERW -- Verify for Writing

7. Addressing descriptor tables (refer to Chapter 5):

8. LLDT -- Load LDT Register

9. SLDT -- Store LDT Register

10. LGDT -- Load GDT Register

11. SGDT -- Store GDT Register

12. Multitasking (refer to Chapter 7):

13. LTR -- Load Task Register

14. STR -- Store Task Register

15. Coprocessing and Multiprocessing (refer to Chapter 11):

16. CLTS -- Clear Task-Switched Flag

17. ESC -- Escape instructions

18. WAIT -- Wait until Coprocessor not Busy

19. LOCK -- Assert Bus-Lock Signal

20. Input and Output (refer to Chapter 8):

21. IN -- Input

22. OUT -- Output

23. INS -- Input String

24. OUTS -- Output String

25. Interrupt control (refer to Chapter 9):

26. CLI -- Clear Interrupt-Enable Flag

27. STI -- Set Interrupt-Enable Flag

28. LIDT -- Load IDT Register

29. SIDT -- Store IDT Register

30. Debugging (refer to Chapter 12):

31. MOV -- Move to and from debug registers

32. TLB testing (refer to Chapter 10):

33. MOV -- Move to and from test registers

34. System Control:

35. SMSW -- Set MSW

36. LMSW -- Load MSW

37. HLT -- Halt Processor

38. MOV -- Move to and from control registers

The instructions SMSW and LMSW are provided for compatibility with the 80286 processor. 80386 programs access the MSW in CR0 via variants of the MOV instruction. HLT stops the processor until receipt of an INTR or RESET signal.

In addition to the chapters cited above, detailed information about each of these instructions can be found in the instruction reference chapter, Chapter 17
